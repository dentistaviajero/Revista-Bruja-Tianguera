# Portadas de reportajes — Bruja Tiangüera

Sube aquí las imágenes WebP de los reportajes. GitHub no conserva carpetas vacías; este archivo mantiene visible la carpeta.

## Nombres reutilizables

- `asia-pop.webp` — Asia Pop / Dragon Ball.
- `coatzacoalcos.webp` — Coatzacoalcos / Dádiva.
- `foro-nomada.webp` — Foro Nómada Cultural / Villa Navideña.
- `mundo-gamer.webp` — Mundo Gamer / Zelda y GTA VI.

Para sustituir una portada, sube la nueva imagen con el **mismo nombre y extensión** y confirma **Replace** si GitHub ofrece reemplazo; si no, edita o elimina la versión anterior antes de subir la nueva. Las notas antiguas que apunten a ese mismo archivo también mostrarán la portada nueva. Conserva imágenes históricas con nombres únicos si deben permanecer.

El orden en los reportajes es imagen, título y texto. Para la Villa Navideña, incluir el aviso de imagen ilustrativa generada con IA.
